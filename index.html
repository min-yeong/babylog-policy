개인정보 처리방침

시행일: 2026-10-24

수집하지 않는 정보

베이비로그는 회원가입이 없고, 입력한 기록을 개발자나 외부 서버로 전송하지 않아요.

광고 식별자, 위치 정보, 연락처를 수집하지 않아요.

기기에 저장되는 정보

닉네임, 태명(선택), 출산예정일, 일기 내용과 감정, 첨부한 사진, 병원·검진·증상·영양제 기록, 화면 테마 설정이 이 기기 안의 앱 저장소에만 저장돼요.

첨부한 사진은 앱 저장소로 복사되며, 사진 보관함의 원본은 변경하지 않아요.

접근 권한

사진 첨부는 사용자가 사진 선택 화면에서 고른 사진만, 촬영은 카메라로 직접 찍은 사진만 받아와요.

Android에서는 카메라·사진·저장공간 권한을 요청하지 않아요. iOS에서는 카메라나 사진을 처음 사용할 때 접근 허용 여부를 물어봐요.

권한을 허용하지 않아도 사진 없이 기록을 남길 수 있어요.

백업 저장과 복원은 사용자가 직접 고른 위치의 파일만 사용해요.

외부 앱으로 전달되는 정보

지도 검색이나 영상 검색을 누르면 "산부인과" 같은 검색어만 선택한 지도 앱 또는 YouTube로 전달돼요. 일기와 기록은 전달되지 않아요.

보관 및 삭제

기록은 사용자가 삭제하거나 앱을 삭제할 때까지 기기에 보관돼요.

내정보의 모든 데이터 삭제 기능 또는 앱 삭제로 기록과 사진, 앱이 임시로 보관한 사본까지 모두 지울 수 있어요.

백업은 일기, 사진, 프로필이 포함된 암호화되지 않은 ZIP 파일이에요. 직접 내보낸 백업 파일은 안전한 위치에 보관하고 사용자가 직접 삭제해야 해요.
